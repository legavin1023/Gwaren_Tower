# 관리자·일반 회원 모드

관리자 계정은 계정 메뉴의 모드 버튼 또는 **내 프로필 → 이용 모드**에서 전환한다. 모바일 계정 메뉴에서는 사람/방패 아이콘으로 표시한다. 일반 회원에게는 전환 옵션을 표시하지 않는다.

- **일반 회원 모드:** 본인의 콘텐츠를 관리하고 평소 회원처럼 사용한다. 운영 메뉴와 타인의 수정·삭제 버튼, 공지 작성과 내보내기 등 관리자 기능을 표시하지 않는다. 해당 모드로 전송한 API 요청에도 회원 권한을 적용한다.
- **관리자 모드:** 기존 관리자/최고 관리자 권한에 해당하는 기능을 사용할 수 있다. 일반 회원 계정이 모드 값을 바꾸어도 권한이 올라가지 않는다.

처음에는 일반 회원 모드로 시작하며 선택은 계정별로 해당 기기의 로컬 저장소에 기억한다. 계정의 DB 등급은 변경하지 않으므로 언제든 관리자 모드로 돌아갈 수 있다. 모드는 이용 화면과 요청에서 사용할 권한을 선택하는 옵션이며 계정 자체의 관리자 등급을 회수하는 기능은 아니다.

전환하면 열린 수정·삭제 창을 닫고 화면과 이미지 캐시를 새 모드로 다시 불러온다. 역극 등 하위 화면도 다시 생성해 이전 모드의 관리 버튼이나 비공개 운영자 열람 기록이 남지 않도록 한다.

API는 `X-Circle-Mode: member` 요청에서 실제 관리자의 유효 권한을 회원으로 제한한다. `X-Circle-Mode: admin`이나 헤더가 없는 기존 클라이언트 요청은 인증된 계정의 실제 권한을 넘지 않는다. `/api/me`와 프로필 저장 응답의 `account_role`은 실제 계정 등급이고 `role`은 해당 요청의 유효 권한이다. 기존 백업 토큰과 OAuth 세션, DB 스키마는 변경하지 않았다.

검증: 전체 테스트 61개 통과. 모드별 API 제한, 실제 등급 보존, 일반 회원의 관리자 모드 위조 방지, 계정별 선택 저장, 모바일 전환 버튼과 기존 기능 회귀를 포함한다.
