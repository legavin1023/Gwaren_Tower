# 로컬에서 화면과 API 실행

프로젝트 폴더에서 `npm.cmd run dev`를 실행하고 http://localhost:8090 을 엽니다.
로그인 화면의 **로컬 개발 모드로 입장**을 누르면 로컬 관리자 계정으로 들어갑니다. Google 로그인이나 운영용 키는 필요하지 않습니다.

- Vue 화면 서버: 8090, CSS/Vue 파일 저장 시 자동 반영
- 로컬 Worker API: 8787, Vue가 `/api` 요청을 프록시
- 로컬 DB: circle-alliance-local
- 로컬 데이터·이미지: `.wrangler/local-development/` (Git 제외)
- 시작할 때 새 로컬 마이그레이션을 자동 적용하며, 기존 로컬 데이터는 유지합니다.
- 최초 실행 시 디자인 확인용 가상 데이터(캐릭터·관계·게시글·댓글·이미지·알림)를 한 번 추가합니다. 다시 실행해도 로컬에서 수정·삭제한 내용은 덮어쓰지 않습니다. 운영 사이트 데이터는 복사하지 않습니다.

종료는 Ctrl+C 한 번입니다. 기존 `npm run serve`나 Worker 개발 서버가 포트를 사용 중이면 해당 터미널에서 Ctrl+C로 종료한 뒤 다시 실행합니다.
주소는 `127.0.0.1` 대신 **localhost:8090**으로 여세요. 개발 로그인·쿠키·요청 출처를 이 주소에 맞췄습니다.

화면과 API를 따로 켜려면 첫 터미널에서 `npm.cmd run db:local` 후 `npm.cmd run worker:dev`, 두 번째 터미널에서 `npm.cmd run serve`를 실행합니다.

개발 전용 `worker/wrangler.dev.toml`과 `worker/dev.mjs`는 운영 배포에 사용하지 않습니다. 운영 배포 스크립트는 기존 `worker/wrangler.toml`과 `worker/index.mjs`를 사용합니다.
로컬 개발 엔트리는 개발 플래그와 localhost 주소를 모두 확인하며, 운영 Google/백업/푸시 키를 사용하지 않습니다.

## 샘플 데이터

서버가 이미 켜져 있다면 `npm.cmd run dev:seed`로 샘플을 추가할 수 있습니다. 로컬 전용 API와 로컬 관리자 로그인만 사용하며, 운영 주소를 지정하는 옵션은 없습니다.
캐릭터 6명(내 캐릭터 3명), 공지·썰·그림 로그 7개, 수락 대기·승인·거절 관계 6개, 댓글·답글·교류 기록 7개, 프로필과 갤러리 이미지 23개, 읽음·안 읽음 알림 5개를 포함합니다.
이미지는 외부에서 가져오지 않은 생성된 테스트 패턴입니다. 가로·세로·정사각 비율과 첨부 10장인 글을 확인할 수 있습니다. 샘플 글에는 [샘플] 표시가 붙습니다.
기존 로컬 데이터와 로그인 세션은 지우지 않으며, 한 번 생성된 샘플은 재실행 시 변경하지 않습니다.
